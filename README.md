# Bergen BikeShare

A bike-sharing management system built with Python, Shiny and SQLite.

## Overview

Bergen BikeShare is an administrative dashboard developed for a fictional bike-sharing company operating in Bergen,
Norway.

The system supports bike fleet management, station monitoring, maintenance operations, subscription analytics, and
trip tracking. 

Originally developed as a university database project, it was later expanded into a portfolio project
with a more structured architecture, improved user experience, and additional functionality. 

## Tech Stack
* Python
* SQLite
* Shiny for Python
* Pandas
